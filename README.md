🧠 Aura: A Modular Voice Assistant Powered by GPT
Aura is a Python-based voice assistant that listens, thinks, and speaks — built from scratch to demonstrate advanced integration of speech recognition, natural language processing, and modular design. It uses OpenAI’s GPT-4o-mini to interpret spoken commands and respond with expressive, context-aware speech.

Communicate technical decisions clearly and document them professionally.

Aura is more than a script — it’s a personal assistant with personality. It includes:

voice.py: Captures and synthesizes speech using speech_recognition and pyttsx3.

brain.py: Handles GPT interactions with robust error handling.

commands.py: Executes system-level tasks and custom logic.

personality.py: Shapes Aura’s tone and behavior.

.env integration: Keeps API keys secure and deployment-ready.

I built Aura to explore how expressive AI can be — not just functional, but conversational. Every module is designed for clarity, reuse, and future expansion. Whether adding memory, wake-word detection, or multimodal input, Aura is ready to grow.
